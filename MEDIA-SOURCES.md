## Verification limits

Source identity/title checks do not prove that YouTube will play every video in every region or browser. Automated YouTube oEmbed requests returned HTTP 403 in this execution environment, and some web fetches were throttled. The site therefore uses direct new-tab YouTube watch links with no iframe dependencies. Browser tests verify site filters, URL structure, target/rel attributes and new-tab navigation; YouTube playback is not claimed as tested. Captions and playback are provided by YouTube.
